# Rajashekar Jaadi — Vanilla Portfolio

A responsive portfolio built with HTML, CSS and vanilla JavaScript. It does not require React, Node.js, npm, a bundler, or external libraries.

## Files
- `index.html` — page content
- `styles.css` — layout and responsive styling
- `script.js` — navigation, project filters, email copy, reveal effects
- `assets/favicon.svg` — browser icon

## Run on Windows
1. Extract the ZIP file.
2. Open the extracted folder in Visual Studio Code (**File → Open Folder**).
3. Optional: install the **Live Server** extension by Ritwick Dey.
4. Right-click `index.html` → **Open with Live Server**. Or double-click `index.html` to open it directly.
5. Edit files and save with `Ctrl+S`.

No terminal commands or package installation are needed.

## Before publishing

## Publish on GitHub Pages
1. Create a public GitHub repository named `rajashekar-vanilla-portfolio`.
2. Upload the **contents** of this folder to the repository root (make sure `index.html` is at the root).
3. Go to repository **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. After deployment, the site should be available at:
   `https://chinnajadi.github.io/rajashekar-vanilla-portfolio/`

If you use a different repository name, replace the final URL segment.

## Features
- Responsive desktop, tablet, and mobile layout
- Mobile navigation menu
- Project category filters
- Scroll reveal effects with reduced-motion support
- Copy-email and back-to-top buttons
- Semantic HTML and keyboard skip link
